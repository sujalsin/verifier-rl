Purpose
-------
Separate four issues: generated program correctness, strict output compliance,
reward informativeness, and verifier coverage. Do not declare one model, reward
shape or optimizer successful merely because some reward now varies.

Frozen changes
--------------
The legacy balanced suite (cache-balanced-probes-0.1), G1/G2/G3, all old scores,
the sandbox runner, source extractor and strict output comparator stay unchanged.
A NEW suite, balanced_v2 / cache-balanced-probes-0.2, has 34 cases: six structural
variants in each of retrieval, expiry, overwrite, multiple keys and ordering,
plus four edge cases. The weighting stays .19 per substantive family and .05
for all edges. Expected outputs still require full exact-list matches per case.
There is no token/format-only bonus and no permissive last-line output parsing.
Default seed 20260929; suite hash:
39e0ca3f31a99bf44c90f9ae55fcd6fae9fbec121d0059046b4ed606ee79649a

Each expiry case includes a first read of an already-expired write, plus a live
value. Other cases cover repeated reads, late first reads, write replacement,
ties, and interleaved keys. This addresses the observed expiry/deletion confound.
Families identify probe patterns, not isolated or proven learned capabilities.

Author-written validation, separate from model results
-----------------------------------------------------
22 fixed controls x 3 suite seeds = 66 control/seed comparisons. Correct code
must score 1; every registered faulty control must fail full acceptance; the
four trivial-output controls must remain within the .05 edge allowance.
Deleting on read while ignoring expiry must fail ALL expiry probes, score less
than under v1, and score less than the matched consumption control with correct
expiry handling. Include compound faults; do not validate only single bugs.
These finite checks do not prove resistance to arbitrary shortcuts.

Observed fixture scores before the model re-evaluation:
  ignore expiry + consume on read: .62 -> .24
  correct expiry + consume on read: .62 -> .5566666666666666
  correct implementation: 1 -> 1
  always-None: .0375 -> .0375
Some other bugs receive MORE partial credit (for example refresh-on-read and
ignore-expiration). Retain the full matrix. This is a targeted coverage repair,
not a proof of uniformly stronger scoring or a controlled coverage-only causal
experiment: both case count and structure changed. Full acceptance and an
independent evaluation remain necessary; do not equate partial reward with
percent of programming capability.

or schema, candidate execution errors, unattributed execution timeouts, output
