# Retired experiment tools

These are completed, historical launchers and protocols, moved out of the active
workflow without changing their bytes. They are not current run instructions.
Some imports and snapshot paths assume their original repository-root location.
Restore a launcher and its referenced protocol files to those original paths
before attempting an explicitly approved reproduction; do not blindly run it.

[manifest.json](manifest.json) records each original path, new path, and SHA-256.
No checkpoints, samples, grading results, or research notes were deleted.
The shared Python modules and regression tests remain active because they are
still imported or needed to validate historical evidence.

The previous README is preserved in [experiment_history.md](../docs/experiment_history.md).
Its command examples and relative links describe the original layout, not the
current entrypoints. The current root README is the workflow guide.
