Offline formula comparison on the SAME saved v2 case outcomes
------------------------------------------------------------
Compare existing weighted partial p, binary full-suite b, and the illustrative
completion-bonus proposal (p+b)/2. The half weight is an explicit diagnostic
choice, not a tuned optimum or a new training default. This proposal preserves
rank order; it changes relative gaps when a group contains a full-suite pass.
If a group contains no full pass, it merely halves all rewards. Group
normalization largely cancels positive scaling (exactly without the denominator
epsilon). Thus a lower score printed for an incorrect program is NOT proof that
its reinforcement was reduced. Binary rewards may remove useful variation.
Compute sample-standard-deviation advantages with epsilon=1e-4, matching the
pinned TRL 0.28.0 formula to floating-point tolerance, not bitwise Torch parity:
https://raw.githubusercontent.com/huggingface/trl/v0.28.0/trl/trainer/grpo_trainer.py
Counterfactual labels on saved rollouts are not alternative training runs; later
rollouts would change if rewards changed. Do not infer a causal learning benefit.

Separate opt-in coverage revision: balanced_v3

The new probes are derived from the task contract and training probe structures,

Validate using existing authored controls plus explicit short-input-only,
